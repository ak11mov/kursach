# Мониторинг криптовалютного рынка

## Описание проекта

Проект представляет собой ETL-пайплайн и аналитический дашборд для мониторинга криптовалютного рынка. Данные о криптовалютах получаются через CoinGecko API, обрабатываются с помощью Python и сохраняются в PostgreSQL. Для визуализации и анализа показателей используется Yandex DataLens.

## Используемые технологии

- **Python 3.10** — получение и обработка данных.
- **CoinGecko API** — источник данных о криптовалютах.
- **Apache Airflow 2.10.5** — автоматизация и оркестрация ETL-процесса.
- **PostgreSQL 17** — хранение данных и истории загрузок.
- **SQL** — обработка данных, создание представлений (VIEW) и подготовка показателей.
- **Yandex DataLens** — создание аналитического дашборда.
- **Ubuntu 22.04 (WSL)** — локальная среда для запуска Airflow.

## Реализованный функционал

1. Получение данных о 10 криптовалютах через CoinGecko API.
2. Обработка полученных данных с использованием Python.
3. Сохранение данных в PostgreSQL.
4. Создание ETL-пайплайна в Apache Airflow с задачами загрузки и проверки данных.
5. Настройка периодического запуска DAG.
6. Создание SQL-представления `crypto_market_dashboard` для подготовки данных к аналитике.
7. Экспорт актуальных показателей в CSV для загрузки в облачный Yandex DataLens.
8. Создание аналитических графиков, KPI-карточек и селекторов.

## Аналитический дашборд

В дашборде предусмотрены следующие показатели и визуализации:

- Количество отслеживаемых криптовалют.
- Суммарная капитализация выбранных криптовалют.
- Общий торговый объём.
- Рейтинг криптовалют по капитализации.
- Изменение стоимости за последние 24 часа.
- Сравнение текущих цен и торговых объёмов.
- Фильтрация данных по криптовалюте и другим параметрам.

## Обновление данных

Сбор данных выполняется ETL-пайплайном под управлением Apache Airflow. История загрузок сохраняется в PostgreSQL.

Для передачи данных в облачный Yandex DataLens используется ручной экспорт актуальных показателей в CSV с последующей загрузкой файла в DataLens.

## Результат

В результате разработан ETL-пайплайн для сбора и хранения данных о криптовалютном рынке, а также аналитический дашборд для сравнения основных рыночных показателей и мониторинга состояния выбранных криптовалют.
